Introduction

Welcome to the V2 API.

Installation

You can install our official Node.js client via NPM:

bash 
npm install @company/api-client

Get User

GET /v2/users/{id}

Example Request

JavaScript 
const client = require('@company/api-client');

client.users.retrieve('user_123')
  .then(user => console.log(user));
